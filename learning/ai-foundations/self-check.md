# 三块基础自测：30 题

做法：先不看材料口头回答，再把解释、例子或公式写进自己的笔记。能独立解释并举例后勾选。今天从 M1—M3 开始。

- [ ] M1：模型、参数、超参数分别是什么？在线性回归中各举一个例子。
- [ ] M2：损失函数与评价指标有什么联系和差别？
- [ ] M3：推导 `L=mean((wx+b-y)^2)` 对 `w,b` 的偏导。
- [ ] M4：梯度下降为什么沿负梯度方向？学习率太大或太小会怎样？
- [ ] M5：用一个两层标量网络演示链式法则。反向传播和优化器分别做什么？
- [ ] M6：为什么神经网络需要非线性激活？
- [ ] M7：训练集、验证集、测试集各用来做什么？怎样避免信息泄漏？
- [ ] M8：训练损失降、验证损失升时，你会检查哪些原因？
- [ ] M9：softmax 怎样把 logits 变成概率？交叉熵怎样惩罚错误预测？
- [ ] M10：比较 SGD 与 Adam 的基本更新思路；解释正则化和 early stopping。
